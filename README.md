# 📊 Project 2 - Power BI Sales Dashboard

## 📌 Overview

This project is an interactive **Power BI Dashboard** created to analyze sales performance and generate business insights. The dashboard helps users understand sales trends, customer behavior, product performance, and other key business metrics through interactive visualizations.

## 🎯 Objectives

* Analyze overall sales performance
* Monitor revenue and profit trends
* Identify top-performing products/categories
* Track customer purchasing behavior
* Build an interactive dashboard for business decision-making

## 🛠️ Tools & Technologies

* **Power BI Desktop**
* **Power Query**
* **DAX**
* **Data Modeling**
* **CSV / Excel Dataset**

## 📈 Dashboard Features

* Interactive KPI Cards
* Sales Trend Analysis
* Category-wise Performance
* Product-wise Analysis
* Customer Insights
* Dynamic Filters & Slicers
* Interactive Charts and Visualizations

## 📊 Key Insights

* Identifies best-selling products and categories.
* Helps monitor sales performance over time.
* Provides insights into customer purchasing patterns.
* Supports data-driven business decisions using interactive reports.

## 📂 Project Files

* `Project_2.pbix` – Power BI Dashboard File
* `README.md` – Project Documentation

## 🚀 How to Us

1. Download the `.pbix` file.
2. Open it using **Power BI Desktop**.
3. Refresh the dataset (if required).
4. Explore the dashboard using slicers and filters.
